# Mindo CLI downloads

Prebuilt `mindo` binaries for macOS, Linux and Windows.
The source code is not public.

- macOS:   `brew install edtk/tap/mindo`
- Linux:   `curl -fsSL https://mindo.fun/install.sh | sh`
- Windows: download the .zip from [Releases](https://github.com/edtk/homebrew-tap/releases/latest)

Then run `mindo auth login`. More: https://mindo.fun/cli
